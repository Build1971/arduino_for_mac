This project was made to test Arduino code for Arduino Uno R2 on a Mac using Xcode. 
The normal arduino .ino is in myProj_ino.cpp.
The contents of this file can be copied into the Arduino IDE as a .ino file.
The pin functions are basically a mockup. Just there to accept a call to these functions without throwing errors...
