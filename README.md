This project was made to test code for Arduino Uno R3 on a Mac using Xcode. 
The normal arduino .ino is in myProj_ino.cpp.
After development of the code in Xcode, the contents of this file can be copied into the Arduino IDE as a .ino file.
The pin functions are basically a mockup. Just there to accept a call to these functions without throwing errors...
So far, random numbers, millis() and micros() were implemented.
